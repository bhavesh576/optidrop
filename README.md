# OptiDrop

**Free Online Tools — No Upload, No Sign-Up, No Cost**

OptiDrop is a fully browser-based toolkit with **330+ free tools** across **18 categories** for images, PDFs, documents, resumes, invoices, calculators, text, developer utilities, health, education, fitness, productivity, travel, design, parenting, fun, home improvement, and more. Every tool runs 100% in your browser — no files are uploaded to any server, no sign-up required, no data leaves your device. Installable as a PWA on mobile and desktop.

**Live at:** [https://optidrop.online](https://optidrop.online)

## How It Works

Every tool in OptiDrop runs entirely in your browser using JavaScript:

1. **Open any tool** — no login, no sign-up
2. **Use the tool** — upload images, enter text, fill in values
3. **Get results instantly** — download, copy, or view output
4. **Nothing leaves your device** — all processing is client-side

## Performance Optimizations

- **Lazy-loaded libraries** — Heavy CDN libraries (jsPDF, pdf-lib, JSZip, heic2any, Tesseract.js, PDF.js, @imgly/background-removal, marked.js, DOMPurify) load on-demand only when the user triggers the action
- **requestIdleCallback** — Non-critical features (command palette, FAB, share bar observer, bookmark prompt, recently-used tools, dark mode toggle) are deferred until the browser is idle
- **Feature guards** — FAQ accordion, search filter, and tools directory only initialize on pages that contain the relevant elements
- **Web Workers** — Image compression, OCR, and background removal run off the main thread with main-thread fallback and 30-second timeouts
- **Object URL cleanup** — All `URL.createObjectURL()` calls have matching `revokeObjectURL()` in reset/cleanup functions
- **Event listener cleanup** — Compare modal removes previous drag listeners before attaching new ones to prevent memory leaks
- **DNS prefetch** — `<link rel="dns-prefetch">` for cdn.jsdelivr.net, cdnjs.cloudflare.com, fonts.googleapis.com, fonts.gstatic.com
- **Resource preconnect** — `<link rel="preconnect">` for Google Fonts with crossorigin
- **CSS preload** — `<link rel="preload" href="styles.css" as="style">` for faster first paint
- **Vercel caching** — Immutable cache for CSS/favicon (1 year), 24h for common.js, 1h for HTML with stale-while-revalidate
- **Security headers** — X-Content-Type-Options, X-Frame-Options, Referrer-Policy on all HTML pages
- **Single-file CSS** — One `styles.css` file with no unused frameworks; Tailwind served locally as tailwind.min.css
- **No build step** — Zero bundler overhead; files served as-is

## Security

- All user input inserted into HTML attributes is escaped via `escAttr()` to prevent XSS
- `showToast()` uses `textContent` for message content (not innerHTML) to prevent injection
- JSON Formatter escapes HTML entities before applying syntax highlighting
- No `eval()`, `new Function()`, or dynamic code execution anywhere in the codebase
- No open redirects — all `window.location` navigations use hardcoded or validated paths
- No forms with external `action` URLs
- localStorage data is isolated under `optidrop_*` namespace keys
- All processing is client-side — no data is sent to any server
- EXIF data output is HTML-escaped to prevent XSS from malicious image metadata
- Markdown preview uses DOMPurify for HTML sanitization
