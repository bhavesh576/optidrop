Combine Multiple PDFs — Merge PDF Files Online

Easily combine two or more PDF documents into a single file. Upload your PDFs, drag to reorder, choose between append mode (sequential) or interleave mode (alternating pages), and download the merged result instantly.

Append vs Interleave Mode

Append mode is the standard merge: all pages from the first PDF, followed by all pages from the second, and so on. This is ideal for combining chapters, sections, or separate documents into one continuous file.

Interleave mode alternates pages between files: page 1 from PDF A, page 1 from PDF B, page 2 from PDF A, page 2 from PDF B, etc. This is perfect for combining front-and-back scans, or merging odd/even page exports into one document.

100% Private — Files Never Leave Your Browser

All processing uses the pdf-lib library running entirely in your browser. No file is ever uploaded to any server, guaranteeing your documents remain private and secure.
