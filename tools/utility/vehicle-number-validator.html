Frequently Asked Questions

Standard Indian vehicle numbers follow the format: 2-letter state code + 2-digit district code + 1-2 letter series + 4-digit number (e.g., MH12AB1234). The new BH series uses: registration year + BH + 4 digits + 1-2 letters (e.g., 22BH1234AA).
BH (Bharat Series) is a new registration format introduced in 2021 for vehicles of defense personnel, government employees, and others who frequently transfer across states. It eliminates the need to re-register when moving to a different state.
