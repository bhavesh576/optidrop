Frequently Asked Questions

The Indian number system uses a unique grouping pattern. After the first 3 digits from the right, digits are grouped in pairs: ones, tens, hundreds, thousands, lakhs (100,000), crores (10,000,000), and so on. This differs from the international system which groups in threes.
100 lakhs make 1 crore. A lakh is 1,00,000 (one hundred thousand) and a crore is 1,00,00,000 (ten million). Similarly, 100 crores make 1 arab.
International format groups digits in threes: 12,345,678. Indian format groups the last three digits, then pairs: 1,23,45,678. Both represent the same number, just with different comma placements.
